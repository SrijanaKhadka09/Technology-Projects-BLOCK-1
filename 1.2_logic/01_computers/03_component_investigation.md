| Component | Function | Key Specification |
|----------|----------|------------------|
| CPU |Executes instructions, performs calculations, and processes data for all programs and system tasks.| Clock speed (GHz), core/thread count, socket type, and architecture. |
| RAM |Provides high-speed temporary storage for active operating system data and running applications.|	Capacity (GB), speed (MHz/MT/s), DDR generation (DDR4/DDR5), and latency (CL). |
| Storage |Provides long-term persistent storage for the operating system, applications, and files (SSD / HDD).|	Read/Write speeds (MB/s), form factor (M.2 NVMe, 2.5" SATA), and capacity (GB/TB). | 
| Motherboard |Serves as the primary circuit board connecting and facilitating communication between all hardware.|	Form factor (ATX, Micro-ATX, Mini-ITX), chipset, socket type, and available PCIe/DIMM slots. | 
| Power Supply |Converts wall AC voltage into direct current (DC) power regulated for each internal component.|	Wattage rating (W), efficiency certification (80 Plus rating), and modularity (Modular/Non-modular). | 
| Cooling |Dissipates heat generated by the CPU and GPU to maintain stable operating temperatures.| Cooler type (Air/Liquid AIO), fan size (120mm/140mm), TDP capacity, and noise level (dBA). |
